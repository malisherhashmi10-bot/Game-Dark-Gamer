# 🏎️ DARK GAMER RACING

Welcome to **Dark Gamer Racing Game!** 🔥

A fast and fun browser racing game built with:

> ⚡ HTML  
> 🎨 CSS  
> 🧠 JavaScript

Avoid enemy cars, survive as long as possible and get the **highest score!** 🏆

---

## 🎮 GAME CONTROLS

| Control | Action |
|---|---|
| ⬅️ | Move Left |
| ➡️ | Move Right |
| ⌨️ Arrow Left | Move Left |
| ⌨️ Arrow Right | Move Right |
